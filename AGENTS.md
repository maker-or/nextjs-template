# OpenCMS project instructions

This repository is the canonical Next.js application generated by OpenCMS. Before building or changing a website connected to OpenCMS, read [`.agents/skills/opencms-project/SKILL.md`](.agents/skills/opencms-project/SKILL.md).

Keep website presentation in `app/` and OpenCMS integration in `cms/`. Use the OpenCMS CLI to synchronize schemas and deploy content.
