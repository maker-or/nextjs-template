# OpenCMS Next.js template

The canonical minimal Next.js application generated by OpenCMS CLI.

## Local development

```bash
npm install
cp .env.example .env.local
npm run dev
```

`dev` is the complete OpenCMS development workflow: it authenticates the CLI when needed, syncs `cms/schema.json` to the development environment, and then starts Next.js. Use only this command during local development; do not run it alongside `npx @maker-or/opencms dev`.

The underlying Next.js-only script is available as `npm run dev:next`. The CLI uses that internal script after it completes the OpenCMS sync so the two commands do not recursively start each other or launch duplicate Next.js servers.

The CLI normally creates `.env.local` and `cms/schema.json` for you:

```bash
npx @maker-or/opencms create
cd your-project
npx @maker-or/opencms dev
```

## How it works

- `cms/opencms.ts` contains the project and API configuration.
- `cms/schema.json` is the developer-owned JSON schema for blocks and content types.
- `cms/client.ts` is the server-only OpenCMS API adapter used by the starter pages.
- `cms/page-renderer.tsx` renders the JSON block content without introducing a visual page builder.
- `/` renders the `home` page, or the first available page.
- `/:slug` renders a page by slug.
- If the API is private or not configured, the routes render a connection state instead of throwing a 500 error.

The template uses OpenCMS's read-only delivery API. It does not contain Clerk credentials or a management API token. The delivery API returns only pages with `published` status for the configured environment. Dashboard and CLI mutations remain protected by OpenCMS authentication.

Set `OPENCMS_API_URL` to the deployed OpenCMS API origin when the site runs outside the local CLI workflow. The template does not silently fall back to localhost.

For development from another device on the same network, the template automatically allows the current machine's non-internal IPv4 addresses for Next.js HMR. Set `NEXT_ALLOWED_DEV_ORIGINS` only when an additional hostname or address is needed.

Schema changes are synced by:

```bash
npx @maker-or/opencms dev
npx @maker-or/opencms deploy
```
